# Concrete portable query proposal (review only)
Contract 00205ec9e719f3aeb96ec1af7f9d644f092bfccc. Production namespace orcsdr::fcc. Experimental implementation remains orcsdr::fcc::research2; no competing UI API.

C++17 proposed types: FixedText<N> {std::array<char,N> bytes; uint16_t length; bool present;}; Frequency {bool present; uint64_t low,high;}; Point {bool present; int32_t lat_e7,lon_e7;}; Geo {enum Mode:uint8_t {none,radius,bbox}; Mode mode; Point receiver; uint32_t radius_m; int32_t south,west,north,east;}; Query {Frequency frequency; Geo geo; FixedText<2> country; FixedText<64> authority; FixedText<128> callsign,license_id; FixedText<256> organization; FixedText<64> service,emission,station_class,status; uint8_t prefix_mask; uint8_t role_mask; uint8_t limit;}; limit 1..16, prefix bits for callsign/license/organization only (authority exact). All present filters AND. Absent filter not wildcard text. Reject invalid UTF8 or too-long queries, bad coordinates, reversed ranges, unknown mask bits. Tolerance uses saturated [max(0,f-t),min(MAX,f+t)]; zero valid numeric bound not missing. Role mask=0 all, scanner default TX plus unknown as separately labeled candidates; RX/allocation never confirmed transmitter. Unknown location allowed for no geo filter; radius requires receiver location, bbox does not. Strict geo excludes unknown geometry and reports count/partial coverage. Antimeridian split, pole handling, geodesic distance (proposal WGS84 or bounded spherical implementation with documented uncertainty; review required), area intersection separate from point distance. No fabricated coordinates.

Result identity {country[2], package_identity[32], entity_type:u16, ref:u64}; stable external identity resolved as source/authority/system/entity/source key; value-owned bounded text fields may report truncation, not truncate identifiers used for joins. Candidate {identity, license identity, low/high, role, optional E7 point, optional distance_m, status, class, reason_bits:uint32, conflict_bits:uint32, provenance ref, display summary, metadata_truncated}; reasons frequency_exact, frequency_overlap, geo_point_near, geo_area_overlap, emission_compatible, status_active, identity_key_match; conflicts protocol_inconsistent, role_rx, allocation_only, unknown_geo, unknown_emission, status_inactive, stale_source. No calibrated probability. Each competing record retained unless same canonical identity; no automatic identity confirmation.
Page {array<Candidate,16>, count, outcome enum pending/no_match/candidates/partial/cancelled/error, coverage enum complete/partial/unknown, availability enum missing/corrupt/unsupported/stale/available, more flag, omitted_unknown_geometry count with validity flag}. Partial when coverage omitted, read fails or work cap hit; never conflate missing database with no_match. Value-owned results; details queried using pinned identity, not row index. Result pages stable for same immutable package generation and query. Deterministic retrieval ordering as wire proposal; ranking separately defined, no scores masquerading as probabilities. Complete result set independent of pagination.

Proposed methods: Storage::size(), read_at(offset,out,len) (checked, read-only); Reader::open(verified immutable package handle); Reader::begin(Query,Cursor&); Reader::step(Cursor&,WorkBudget,CancelToken,Page&); Reader::detail(identity, bounded fields, WorkBudget); Reader::close only when cursors released. WorkBudget {uint32_t max_reads,max_bytes,max_candidates}; cancellation checked before each read, no unbounded decompression. Cursor opaque caller-owned fixed buffer; no copying or serialization; bound <=8 KiB proposed, not qualified. Worker pins generation and read handles, uses existing coordinator ticket and lifecycle keys, no I/O on UI/DSP. Country iteration over installed package set snapshot, stable order, absent country explicit. No new Settings/Discovery/M5GFX. Cache keys include normalized query, package and location generation. Cache target and page size to be evaluated physically. Production API not implemented; prototype only frequency query and opaque numeric IDs. Independent tester should review semantics and golden vectors before acceptance.
