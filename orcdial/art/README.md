# Dashboard selector artwork

The transparent [source atlas](dashboard-selector-atlas.png) was generated with the built-in imagegen tool. Its first 15 cells were cropped and scaled to 64 × 64 transparent PNGs in `../assets/dashboard/` for firmware embedding. Home uses the existing Orc badge. The source atlas is kept for future visual revisions and is not embedded in firmware.

ADS-B now uses the atlas's aircraft tile, formerly used by Airband. Airband uses the new [control-tower source](airband-control-tower-source.png), scaled to `../assets/dashboard/airband.png`. The tower was generated with the built-in imagegen tool using the aircraft and FM icons as style references. Prompt: "Generate a new airport air-traffic-control tower with a tall stem, broad glazed cab, wraparound blue windows, and a small roof antenna; match the existing luminous cyan and blue metallic selector art; centered transparent cutout, readable at 64 × 64; no plane, broadcast mast, text, border, or warm colors."

Final prompt:

> Use case: stylized-concept. Asset type: single 4-by-4 sprite atlas for a 240-pixel circular radio-controller dashboard selector. Create EXACTLY sixteen separate square pictorial icons in a rigid equal 4x4 grid. Transparent background and clear empty gutters between tiles; each icon centered well inside its own tile, with no overlap into adjacent tiles. Style: premium OrcSDR instrument graphics, polished luminous cyan, electric blue and orc-badge neon green on transparent/dark-compatible ground, crisp forms, readable when reduced to 48x48 pixels. Rich illustrated symbols with subtle glass/metal depth, not primitive line icons. Absolutely NO words, letters, numbers, labels, borders, UI frames, orange, amber, brown, yellow, or watermark. Tile subjects in left-to-right, top-to-bottom order: row 1: FM broadcast radio tower with radiating waves; AM medium-wave radio tower with broader low-frequency waves; weather cloud with radio-wave beacon; aviation aircraft silhouette. Row 2: marine ship on waves; CB handheld radio microphone; ADS-B radar dish with aircraft; communications satellite with solar panels. Row 3: LoRa mesh nodes linked; RF laboratory spectrum analyzer instrument; P25 public-safety radio; shortwave globe and antenna. Row 4: POCSAG pager; Wi-Fi access point with waves; settings gear; OrcSDR home badge-inspired green orc face. Keep every symbol recognizable and visually distinct at tiny scale. The output is the icon atlas itself, square, flat front view.
