# OrcDial control matrix

Checked against `dashboard_registry` and dashboard handlers on `origin/main` 11cc19e. The Tab5 is authoritative. `PENDING` means the action or bounded wireless state is not yet exposed to OrcDial; the Dial must show unavailable/`--`, not guess. `RTL_UI ACTION` commands require authentication. `RTL_UI OPEN` also requires authentication. The ESP-NOW protocol must route to the same handlers without spoofing touch coordinates.

Initial control priorities: implement and test semantic mapping on the Dial first; never emit a frequency tune for ADS-B, LoRa, Wi-Fi, P25 default, POCSAG default, CB, Marine, or Weather. Missing Tab5 semantic handlers remain `PENDING` rather than silently tuning a different dashboard. The standard build now includes an OrcDial ESP-NOW C6 endpoint, but a host build is not Tab5 radio-link evidence.
