# International source requirements — US, CA, AU, JP
Owner direction 2026-11-27: Australia and Japan are minimum required international coverage alongside US and Canada. This is a scope requirement, not proof of implemented coverage or permission to distribute data. Existing three-agent ownership remains unchanged.

## Australia (AU), ACMA
Official sources:
- https://www.acma.gov.au/radiocomms-licence-data (terms, full dataset, API; checked 2026-11-27)
- https://www.acma.gov.au/help-register-radiocommunications-licences-rrl (updated 2026-10-26)
- https://cdn.acma.gov.au/offline-rrl/index.html
Full register provided as CSV files and reference documents in ZIP; difference files available daily, data regenerated periodically. Prefer the complete download, not limited table exports or live API (Digital ID required for API). Inspect actual download, file inventory, reference keys and units. Model licences, sites, TX/RX assignments/registrations, antennas, spectrum/access/broadcast areas, frequency ranges, dual-band roles and published source coordinates. Class-licensed devices may not appear in RRL. Record exclusions; no site inference from client address.
Terms reviewed: ACMA permits software incorporation and distribution of derivatives subject to licence conditions. Clause 8 bars reproduction/distribution of identifying client information of natural-person licensees in derivatives; clauses 6–7 restrict use of client information. Implement source-specific minimization and enforce removal before generating any redistributable artifact (including indices, strings, logs, metadata and lookup details). Treat ambiguous client type conservatively pending review. Preserve required attribution exactly: "Based on Australian Communications and Media Authority information". Review current terms and intended use before release; do not treat this as unconditional redistribution clearance. No archive downloaded during this coordinator review.

## Japan (JP), MIC / 総務省
Official government API catalog https://api-catalog.e-gov.go.jp/info/en/apicatalog/view/46 identifies Radio Station Information Search Web-API (無線局等情報検索 Web-API), REST JSON/XML/CSV. Catalog links https://www.tele.soumu.go.jp/j/musen/webapi/; this documentation URL could not be opened during coordinator review. Verify current endpoint/specification, quotas, result count, pagination, permitted acquisition/caching/redistribution, coverage and privacy before large downloads. Prefer authorized bulk snapshot if available. Otherwise test permitted bounded queries, partition by documented filters (e.g. region/service if supported), reconcile counts/duplicates and detect changes during extraction; no evasion of limits. Record missing categories and timestamp consistency. Contact MIC for authorized offline bulk access if needed. No national dataset or working API query verified. Preserve native Japanese Unicode, stable source IDs, original terminology and precision, source administrative location versus actual transmitter geometry. Romanization or translation optional and explicitly derived; test native script rendering and query normalization. Never manufacture coordinates or identity from coarse administrative labels. Separate equipment certification from station licensing. No mandatory online lookup for OrcSDR user.

## Package and acceptance
Separate country-wide installable data packages (US/CA/AU/JP); one shared native service, country/authority-scoped identities and immutable generation sets. Country selection may be explicit or suggested from receiver location, not a hard exclusion at borders. All-installed search remains available subject to bounded resources and explicit coverage. Preserve original source semantics, regulatory evidence vs observations, deterministic pagination and separate detail hydration. Full-country package means complete within documented permitted public source coverage; not every transmitter. For each source: raw acquisition hashes, publication date, schema, counts, exclusions and rights, deterministic build, signed manifest, semantic admission, independent queries and privacy tests, actual memory/latency evidence. No country called supported until gates passed. UK/NZ and other sources remain expansion candidates, no additional branch. Research owns adapters and data, testing independently qualifies, coordinator owns integration. Local Antigravity supports network-enabled acquisition.
