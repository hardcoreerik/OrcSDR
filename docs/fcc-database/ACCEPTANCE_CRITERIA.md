# Acceptance gates
Full nationwide scope with source-by-source coverage, exclusions and record counts verified against official snapshots; no regional user packages. Deterministic builder, manifest/signature validation, source hashes, version/rollback, interrupted updates, corrupted/truncated/overflow/invalid UTF-8/path traversal/unknown schema, no SD and no network. Independent oracle exact/range/callsign/geographic/combined, long interval, duplicate frequency, competing IDs, missing coordinates, cross-border, antimeridian/poles, status and emissions. Validate pagination, deterministic tie-break, queue saturation, cancellation, ABA/stale generations, SD ejection, update/remove during query, no accidental live/replay mixing. Test retained widgets with real render code, no full-screen clear for progress/value changes. Targets only: cached <1ms, typical uncached <20ms, complex geo <100ms, working core <256KB, optional bounded PSRAM, zero lookup-induced IQ drops and audio underruns. Report p50/p95/p99/max, cold vs warm, dataset/SD characteristics, memory high-water and stack, queue depth, scan/audio/decoder counters, baseline vs load. Host correctness and sanitizers; ESP-IDF compile; physical qualification separately. No claims based on synthetic tiny fixtures or compile alone. Require raw logs and exact commits; owner authorizes final main merge.

## Performance research objectives (not attained)
Original targets remain provisional acceptance envelope: cached <1 ms; typical uncached <20 ms; complex geo <100 ms; core <256 KiB; zero lookup-induced IQ/audio losses. More aggressive optimization targets/stretch: cached 500/50 us; frequency existence 1 ms/100 us (discrete membership only, not complete licensing query); indexed frequency 5/1 ms; frequency+geo 10/3 ms; full detail 20/5 ms; repeated scanner 200/1000 queries/s; core 256/64 KiB. No worst-case bound on completion of unbounded result sets; specify capped page and total results, time to first page and full enumeration, max step time, cancellation latency and backlog. Report cold/warm/repeated/concurrent p50/p95/p99/max and actual bytes, read transactions, CPU and elapsed including queueing. All core allocations, page buffers, stacks, allocator overhead and optional PSRAM indexes accounted separately and together; no cap silently waived. No production claim from synthetic modeled I/O. Exact, range and interval-only gaps must return complete truth or explicit partial/error. See PERFORMANCE_ARCHITECTURE_REVIEW.md.
