# Architecture
Canonical source 870454241c0d58af246755a5263a8e3ead6835c2; main remains the base. Digital Voice reference only 9bd6cf017606867172f52fd1f5779ec4484262ce (feature/dmr-digital-voice-foundation); do not merge it as a dependency. Pipeline: official snapshots → host source adapters → normalized records with provenance → deterministic signed national package → existing Data & Maps delivery worker → immutable generation on SD → bounded random-access portable reader → asynchronous service → immutable UI candidate snapshot. No network in query path. Core and generation code owned by research; coordinator owns request lifecycle and UI/delivery adaptation; testing independently implements oracle. Research proposes exact wire layout for review under DATABASE_FORMAT; no incompatible divergence. Separate observed and regulatory identities. Worker owns read handles; query captures package and receiver-location generations; old packages remain usable until readers release; activation serialized with install/remove; reject late results. Bounded queue, nonblocking submit/poll, explicit busy/cancelled/partial/error. Separate country coverage and query outcome. Use shared storage abstraction, time-sliced SD access coordinated with radio/logging, not direct FAT writes from UI/DSP. No UI draws from workers. Optional PSRAM cache measured and capped; no background preload of all records.

## Performance architecture decision (experimental, not wire freeze)
See PERFORMANCE_ARCHITECTURE_REVIEW.md. Prefer independent discrete frequency directory and augmented interval section. Directory miss never suppresses interval lookup. Retrieve lightweight authorization references first; hydrate larger records on demand under same pinned generation. Default experimental page 4 KiB; compare 2 and 8 KiB at identical wire format/cache budget and report both reads and bytes, including interval and hydration storage. Optional compressed unique-frequency dictionary in bounded PSRAM only after real U and radio headroom measured; fall back to sparse paged index without correctness loss. Neither benchmark nor v2 shard is production code. Require explicit semantic validation gate bound to immutable authenticated generation; index ordering and tree bounds must be verified before any lookup can report complete/no-match. See current handoffs.
