## Decision
Accept separate discrete and augmented range indexing as preferred experimental direction. Preserve v1 reference; v2 candidate not frozen. Stage A optional bounded immutable frequency directory, sparse fallback, delta/compressed offsets and dictionary measurements; stage B independent interval lookup even on negative membership; C lightweight stable authorization/country/authority/status/role/geometry/source references and observed request identity/generation; D lazy details, same pinned generation; E async service with bounded work and independent subscriber tickets, no radio path I/O. Hash/radix/membership/learned indexes are alternatives to evaluate only after real counts; no false-negative filter allowed, learned bounds must fall back safely. Interval tree worst-case O(B) remains; measure nested/overlapping intervals and actual output costs.
