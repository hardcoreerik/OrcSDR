# FCC Database — scope
Native OrcSDR station license lookup, not a separate product or repository. Offline after installation; no account, key, subscription, mandatory desktop application or user-run builder. Ship complete nationwide packages, not regional user packages; cover all relevant publicly available FCC licensing services/bands with explicitly declared gaps. International adapters and multi-country lookup are architectural requirements. Preinstall only if measured storage permits. Shared native C++ service independent of any decoder, with Digital Voice Discovery first. No full SQL engine or full database in RAM. Existing Settings → Data & Maps and M5GFX conventions. No RF degradation, TX, scanner redesign or main merge without owner authorization.
