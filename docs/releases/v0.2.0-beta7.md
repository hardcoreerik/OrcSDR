# OrcSDR v0.2.0-beta7

This beta integrates `esp_rtl_sdr` v0.8.0-rc3 and the current native Tab5
dashboards. The M5Burner custom package contains separate images for the
bootloader at `0x2000`, partition table at `0x8000`, and application at
`0x10000`. Normal upgrades must not erase flash; no image targets the NVS
partition at `0x9000`.

Use the `local-m5burner.zip` custom package. Do not select the ZIP as a raw
single-image firmware file.
