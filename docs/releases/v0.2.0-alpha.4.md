# OrcSDR v0.2.0-alpha.4

`v0.2.0-alpha.4` is the current prerelease for the M5Stack Tab5 and RTL-SDR Blog V4. It is intended for deliberate hardware testing, not unattended deployment.

## What changed

- ScreenController gives Home, FM, P25, ADS-B, LoRa, Settings, and documentation capture one visible-screen owner.
- Settings returns to the originating dashboard; background RTL work requests a UI handoff rather than drawing directly.
- Documentation capture claims and restores screen ownership explicitly.
- The native ESP-IDF build uses ESP-Hosted 2.12.6, M5GFX 0.2.22, and M5Unified 0.2.17.

## Status boundaries

- FM receive, stereo audio, presets, and health are implemented and live-hardware verified.
- P25 clear-voice following, ADS-B, LoRa receive, AM, WX, CB, and Browse remain experimental.
- P25 encrypted voice is not decoded; LoRa has no transmit path.
- Wi-Fi and Companion are optional. Normal on-device operation does not require either.

See the [feature-status guide](../user-guide/feature-status.md) for the complete current matrix.

## Build and test

Use the native ESP-IDF workflow only:

```powershell
Set-Location .\apps\orcsdr-tab5
.\tools\build-tab5-idf.ps1
```

Do not use PlatformIO. Before flashing an alpha build, preserve a known-good device image. Build success, flashing, and physical radio acceptance are separate evidence gates.

## Documentation captures

The README gallery uses authenticated, hash-verified 1280×720 captures from the Tab5 release build. Reproducible screens remain visibly marked `DEMO`; live RF status is never inferred from a static image.
