# OrcSDR v0.2.0-beta.1 prerelease notes

This prerelease introduces the ordered Tab5 M5Burner route: install the
temporary **OrcSDR Hosted 3.0.6 Bridge** first to synchronize the internal C6,
then install final **OrcSDR**. Normal upgrades do not erase P4 NVS.

The public release is blocked until private M5Burner hardware acceptance has
recorded exact-tag P4/C6 match, Home/FM/RTL-SDR/Wi-Fi/RF24 behavior, and the
Windows installer safeguards.
