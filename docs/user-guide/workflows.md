# Common workflows

## Listen to FM

Open NAV, select FM, seek or enter a frequency, then adjust the shared header volume. Use RF Health if sample rate drops or audio underruns increase.

## Follow P25

Select P25, enable Survey, wait for a synchronized control channel, and leave Auto Follow enabled. Hold a talkgroup only after it appears in decoded activity.

## Select an ADS-B aircraft

Save the receiver location, open Radar or List, tap an aircraft, then open Target. The selected ICAO remains consistent across all ADS-B panels.

## Capture LoRa activity

Select the correct channel, spreading factor, and bandwidth. Start the bounded IQ or packet log, wait for activity, stop it, then retrieve the resulting SD file through the documented hash-verified transfer tool.
