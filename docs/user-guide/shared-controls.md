# Home and shared controls

## Home

Home reports receiver readiness, power, host connection state, and access to global Settings. It is safe to use OrcSDR without an authenticated host.

## Volume

Audio dashboards show a speaker icon and global numeric level in the header. Tap it for volume down, mute/unmute, and volume up. The tray closes after four seconds and repaints only its header region. Mute and volume are independent; changing the level does not silently unmute.
