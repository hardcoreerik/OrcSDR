# Downloads and releases

Use GitHub Releases for notes and tags. On Windows, clone the tagged tree and run `.\install-orcsdr.ps1` from the repo root. That script installs `requirements.txt`, flashes the P4, and checks ESP-Hosted 2.12.6 on the Tab5 C6. Verify SHA-256 before trusting extra SD data packs. Generated MP4 walkthroughs are upload-ready artifacts and are not stored in normal Git history.

The Pages site is deployed only from merged `main`. A pull request build validates the guide but cannot publish it.
