## Installed ESP-IDF transport review

Read the installed 5.5.4 `components/esp_http_server/src/httpd_ws.c` and
`httpd_main.c` before choosing integration mechanics:

- `httpd_ws_send_data_async` allocates a transfer for every call and queues
  work onto the HTTP server. It does not by itself isolate socket backpressure.
- `httpd_ws_send_frame_async` calls the session send function for the header
  and payload, checking only negative results (not short positive writes).
- `httpd_queue_work` can wait indefinitely on a semaphore when
  `CONFIG_HTTPD_QUEUE_WORK_BLOCKING` is enabled.
- Default socket send timeout is five seconds.

Therefore merely calling an API named async from DSP would violate the design.
The transport still needs fixed staging, a non-producer scheduling context,
bounded enqueue/send behavior, short-write failure handling and safe teardown.
No ESP-IDF dependency or source modification has been made.

## Control endpoint implementation and native compile

Strict command parsing replaces prefix matches and unchecked `atoi`: exact
commands, bounded decimal frequency, known supported dashboard IDs. Embedded
NULs, trailing junk and overflow are rejected. A serialized single slot rejects
a second command instead of overwriting the first. HTTP reports 202 Accepted
(queued, not RF success), 409 Conflict (busy), 400 invalid input, 403 foreign

non-browser trusted-LAN access; this is not authentication. Rejected unread

## Transport/PCM integration draft (not acceptance-ready)

Working-tree changes after `7a6a490` add `web_audio_transport.{hpp,cpp}`,
register `/api/audio/stream`, enable native WebSocket support and disable the
blocking work-queue option. A PSRAM-stack scheduling task submits at most one
pending HTTP work item. The HTTP task owns both subscriber slots and fixed
staging. The send override uses MSG_DONTWAIT and treats short writes as failure,
shutting down the affected connection. The producer tries ownership once and
counts/drops contention rather than waiting. PCM demand includes remote
subscriptions in analog/P25 production; shared conditioned PCM publication now
precedes local speaker buffers. Local-muted PCM bypasses speaker buffering.

These mechanisms are implemented but concurrency/lifecycle/backpressure are
NOT yet runtime-verified. Retune/source-generation propagation remains open;
At this draft checkpoint the browser still used the old WAV UI; the later

## Anchored audio clock and browser-demanded spectrum checkpoint (historical)

60-second protocol probe: 2,841 packets, 2,727,078 samples, 1,474 position
gaps, zero generation changes, 2,726,793 nonzero samples, and 45,451.3

relative 20 ms worker delay accumulated loop/queue overhead, so the sender
