# W01 Live Watch — source-aligned preview package

> **Status:** reference illustrations of W01 on the `chatgpt/drone-watch-phasing-20261026` branch. They are **not pixel-perfect M5GFX/native framebuffer captures, not screenshots of a real Tab5**, and do not prove live Bluetooth reception. `drone_watch_dashboard.cpp` remains the authoritative UI source.

## What's in this folder

- [`render_source_layout.py`](render_source_layout.py): reproducible Pillow-based host visualization of the actual W01 screen coordinates, RGB565-derived palette, text copy, touch-button and category positions. This is a **manual** source translation, tied to W01 renderer blob `b222a1e0f9fe19e9dbc2f9e11fad9878e7000b21`; it is **not** a compiled or pixel-identical M5GFX renderer.
- `W01_as_built_1280_default.png`: source-unavailable landing screen at **1280×720**.
- `W01_as_built_1280_sources.png`: same at 1280×720 with read-only C6 Sources inspector open. The display's Wi-Fi link and battery are **illustrative**, not measured.
- `W01_as_built_720_default.png`: 720×720 adaptive approximation, without hardware display qualification.
- `W01_as_built_720_sources.png`: 720×720 with C6 Sources inspector.
- `W01_source_aligned_comparison.png`: side-by-side contact sheet, **1280×1080**, not a firmware target size.

The images are generated by the companion [GitHub Actions renderer workflow](../../../../.github/workflows/drone-watch-preview-render.yml). It commits the five PNGs to **the existing feature branch** when the renderer changes; it never flashes or builds firmware. The workflow also uploads an independent image artifact. If a PNG is missing, run the generator locally rather than claiming it has already been committed.

## Generate locally

**Linux**, from the OrcSDR repository root:

```bash
python3 -m pip install Pillow==12.3.0
python3 docs/drone-watch/previews/w01/render_source_layout.py 2>&1 | tee ./drone-watch-preview-render.log
python3 - <<'PY'
from pathlib import Path
from PIL import Image
base = Path("docs/drone-watch/previews/w01")
expected = {
  "W01_as_built_1280_default.png": (1280,720),
  "W01_as_built_1280_sources.png": (1280,720),
  "W01_as_built_720_default.png": (720,720),
  "W01_as_built_720_sources.png": (720,720),
  "W01_source_aligned_comparison.png": (1280,1080)
}
for name, dims in expected.items():
    assert Image.open(base / name).size == dims, (name, dims)
print("5/5 illustration dimensions verified")
PY
```

**Windows PowerShell:** install `Pillow==12.3.0`, then edit the generator's `FONT` variable to point at an installed DejaVuSansMono font (or equivalent monospace font). The generator's default absolute font path is for Linux. Capture an execution log in the invocation folder:

```powershell
python docs/drone-watch/previews/w01/render_source_layout.py *>&1 |
  Tee-Object -FilePath .\drone-watch-preview-render.log
if ($LASTEXITCODE -ne 0) { throw "Preview generation failed" }
```

Do not include licensed font binaries in the repo. The generator requires a **system-installed** font and includes no `.ttf` files.

## What this verifies — and does not

The Python visualization follows the production W01 *layout* and source strings, but it deliberately approximates M5GFX `setFont(nullptr)` text, its actual `orc_badge` glyph/logo, arc and icon rasterization. Header control positions follow the existing `dashboard_audio_control.cpp`. Neither perfect pixel parity nor 5-inch text legibility has been established by this package. Original six-screen concept prototypes use a **different generated C++ draw-command renderer** and must not be described as the current W01 firmware.

A real pixel-exact test must render the production M5GFX code into a framebuffer under the exact target fonts, compare decoded RGB565 pixels and touch targets, then pass a physical 1280×720 Tab5 test. OrcSDR's existing W01 host drawing recorder confirms drawing *calls*, not pixel values.

**Evidence gating:** `host preview` ≠ `native build` ≠ `physical display` ≠ `live Remote ID reception`. The current source screen reports `SOURCE UNAVAILABLE` until separately verified acquisition exists.
