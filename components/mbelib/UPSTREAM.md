# mbelib IMBE subset

This component contains only the files needed for P25 Phase I IMBE 7200x4400
voice decoding from [szechyjs/mbelib](https://github.com/szechyjs/mbelib), pinned
from commit `9a04ed5c78176a9965f3d43f7aa1b1f5330e771f`.

The upstream ISC license is preserved in `COPYRIGHT` and every source file.
To update, replace the listed source/header files from a reviewed mbelib commit,
record its hash here, and run the OrcSDR P25 self-check plus the native Tab5 build.
